**接线示意：**
```
电源正极 → 限流电阻(10kΩ) → 阴极(钨针) → 等离子体 → 腔壁(阳极) → 电源负极

```

| F2 | 退火设备 | 管式炉 或 丙烷喷枪，铁丝弯制前退火软化 |

### 3.5 加工步骤

1. 铁丝切段（每段 15~20cm）
2. 退火（管式炉 600℃ × 30min 或喷枪烧红后缓冷）
3. 按模具弯制（把铁丝按进 3D 打印模具的槽位，手工沿槽弯曲）
4. 定型（弯好后套在模具上二次退火，取出后几何固定）
5. 表面处理（阳极氧化/涂漆/裸丝，按实验计划）
6. 拍照存档（白底，标尺，标注几何参数：绕数/环径/丝径/表面态）
7. 装入绝缘支架，待实验

## 4. 诊断探头

### 4.1 Bdot 探针（自制，×4）

| 编号 | 组件 | 规格 |
|---|---|---|
| B1 | 漆包线 | Φ0.1mm 聚氨酯漆包铜线，耐温 155℃ |
| B2 | 线圈骨架 | 塑料管 Φ3mm × L5mm（3D打印或切塑料管） |
| B3 | 绕线 | 在骨架上密绕 200 匝，两端引出 |
| B4 | 静电屏蔽 | 外层套铜网（编织网），铜网接地（接腔壁） |
| B5 | 输出端 | 屏蔽线（同轴电缆），内芯接线圈一端，外屏蔽接铜网+腔壁 |

**参数计算：**
- 线圈面积 $A = \pi (1.5\text{mm})^2 = 7.07\text{mm}^2$
- 匝数 $N = 200$
- 灵敏度 $S = N \cdot A = 1.41\times 10^{-3}\ \text{m}^2$
- 输出 $V = -S \cdot dB/dt$：若 $dB/dt = 1\ \text{T/s}$，输出 1.41mV

**安装：** 4 个 Bdot 探针贴腔壁内侧，方向分别沿 X/Y/Z 轴 + 一个斜向参考。用真空胶粘在壁上，引线从法兰引出。

### 4.2 朗缪尔探针（自制，×1）

| 编号 | 组件 | 规格 |
|---|---|---|
| L1 | 探针丝 | 钨丝 Φ0.5mm，尖端磨成 30° 锥角，露出长度 5mm |
| L2 | 绝缘套管 | 氮化硼（BN）管，外径 Φ3mm，内径 Φ1mm，长度 20mm |
| L3 | 安装 | BN 管焊在 CF35 法兰上，探针丝从管内穿过，后端接扫描电源 |
| L4 | 扫描电源 | 0~±100V 锯齿波，频率 10Hz~1kHz，电流输出能力 ≥10mA |

**操作：** 锯齿波扫描，示波器同时记录电压和电流，实时拟合 I-V 曲线得到 $T_e$ 和 $n_e$。
