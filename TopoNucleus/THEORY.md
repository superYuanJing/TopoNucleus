## 1. 层级模型

整个假设拆成五层，每层建立在前一层之上：

```
L1  鞘层电势阱        ← 高置信，文献充分
  ↓
L2  几何强制轨道缠绕   ← 中置信，理论支持+模拟支持，无直接实验
  ↓
L3  拓扑涌现与自持     ← 核心赌注，本项目要验证的
  ↓
L4  螺度自举           ← 极低置信，类比外推
  ↓
L5  核反应耦合         ← 远期假设
```

**本项目 Phase 0 只验证 L1→L3 链条。** L4/L5 不在本阶段讨论范围。

## 2. 第一层：鞘层电势阱（高置信）

### 2.1 物理

导电物体放入等离子体中，电子热速度远大于离子，电子先贴上去 → 物体表面带负电 → 形成鞘层（sheath），产生电势阱。

经典公式（轨道运动限制理论，OML）：

$$V_s = -\frac{k_B T_e}{2e} \ln\left(\frac{m_i}{2\pi m_e}\right)$$

典型值：氩等离子体 $T_e \sim 3\text{eV}$，鞘层电势 $V_s \sim -15\text{V}$。

### 2.2 对种子的意义

- 种子表面带负鞘层电势 → 排斥电子、吸引离子
- 离子撞上表面 → 溅射/二次电子发射 → 弹出来的粒子带方向性
- **方向性被扭结几何调制** → 出射方向不是各向同性，而是沿曲率方向偏折

这就是"几何引导"的起点：不是骨架产生场，是骨架的几何形状**调制了粒子出射的方向分布**。

### 2.3 文献锚点

- Mott-Smith & Langmuir (1926) — 鞘层理论奠基
- Chen, *Introduction to Plasma Physics*, Ch.5 — 鞘层基础
- 尘埃等离子体实验（Fortov et al., 2005）— 微米颗粒在鞘层中自发排成链/晶格，证明"导电障碍物能组织粒子"

## 3. 第二层：几何强制轨道缠绕（中置信）

### 3.1 核心思想

粒子从种子表面弹射出来时，出射方向被扭结面的局部曲率约束。对于扭结几何（环绕数 > 0），沿切方向的轨迹被迫反复绕行。

数学表述：

设扭结曲线的切向量为 $\vec{t}(s)$，粒子出射方向近似沿 $\vec{t}(s)$ 或其反射方向。对于非平凡扭结，任何沿切方向的轨迹都满足：

$$\oint_C \vec{t} \cdot d\vec{l} \neq 0$$

即轨迹的环绕数非零——它绕不出这个拓扑。

### 3.2 为什么环形不行但扭结可能行

- **圆环**：粒子沿环面切向飞出，穿过环心后就直线逃逸。轨道不闭合。
- **扭结**：扭结的曲率在空间中没有"逃逸方向"——任何局部切向都被迫绕回。这跟圆环的根本区别是**纽结理论里的非平凡同伦类**。

### 3.3 从轨道到流形

单个粒子轨迹是微弱的。关键是**大量粒子的统计效应**：

- 出射方向被几何调制成非均匀分布
- 非均匀出射 → 局部密度涨落 → 碰撞动量交换
- 动量交换使邻近粒子轨道进一步对齐 → 涡旋涌现
- 涡旋沿骨架延伸方向传播 → 多个涡旋互相嵌套

这个过程跟以下已知现象同构：
- 尘埃等离子体中的库仑耦合链（Fortov）
- 磁流体中的 Taylor 弛豫（Taylor 1974）
- 二维流体中的点涡旋自组织（Kida 1981）

### 3.4 文献锚点

- Moffatt & Ricca, *Helicity and the Calugareanu Invariants*, Proc R Soc A (1992) — 扭结拓扑不变量
- Khesin & Misiolek, *Euler equations on homogeneous spaces*, 1998 — 拓扑流体力学
- Smiet et al., PRL 115, 095001 (2015) — 数值证明螺旋初始条件重排成嵌套环面
- Yeates et al., Proc R Soc A 471:20150012 (2015) — 拓扑度约束弛豫终态

### 3.5 这是"核心赌注"的第一半

已有文献证明"扭结几何能约束磁/流体场线"。但那些是**初始条件里直接给了磁场扭结**。

我们的赌注是：**实体导电扭结能否在纯等离子体（无预置磁场）中，仅通过鞘层+几何引导，产生等效的拓扑约束？**

没人验证过。这就是 Phase 0 要回答的问题。

## 4. 第三层：拓扑涌现与自持（核心赌注，低置信）

### 4.1 正反馈链条

如果 L2 成立（轨道被缠绕），接下来：

1. 缠绕轨道 = 定向电流（电子/离子沿轨道集体运动）
2. 电流产生磁场 $\nabla \times \vec{B} = \mu_0 \vec{J}$
3. 磁场反过来约束粒子沿闭合轨道（磁镜/磁阱效应）
4. 更多粒子被约束 → 更多电流 → 更强磁场 → 正反馈

### 4.2 自持条件

正反馈要赢过耗散。耗散主要来自：
- 电阻耗散（磁能→热）：$\eta J^2$
- 粒子碰撞（轨道随机化）
- 辐射损失

自持判据：**磁能注入速率 ≥ 耗散速率**。

磁能注入来自粒子动能（轨道运动的集体效应），不需要外部供能。

### 4.3 泰勒弛豫作为锚点

Taylor (1974) 证明：电阻性等离子体中，磁螺度 $K = \int \vec{A}\cdot\vec{B}\,dV$ 在快速弛豫中近似守恒，系统弛豫到无力态：

$$\nabla \times \vec{B} = \lambda \vec{B}$$

其中 $\lambda$ 沿力线为常数。

**我们的类比：** 如果种子诱导的轨道缠绕产生了等效螺度（即使没有外部注入），系统可能弛豫到类似泰勒态的构型，但**螺度来源是内部几何引导，不是外部注入**。

### 4.4 为什么这可能成立

- Smiet 2015 证明：即使初始螺度分布不均匀，系统也能重排成嵌套环面
- Hopf fibration 数值（AIP Pop 2017）证明：局域扭结场可达 Grad-Shafranov 平衡
- 我们的种子相当于**把初始螺度"硬编码"进几何里**，让等离子体自己读出这个拓扑

### 4.5 为什么也可能不成立

- 低温等离子体电阻率高，螺度可能在形成前就耗散殆尽
- 鞘层电势太弱（~15V），不足以驱动足够强的集体运动
- 碰撞频率太高，轨道在闭合前就被随机化
- 扭结尺寸（厘米级）远大于拉莫尔半径（毫米级），几何约束可能被平均掉

**这些都是合理的担忧。Phase 0 就是来分辨"成立/不成立"。**

### 4.6 判据（详见第7节）

- 磁探针测到关断后 B 不按单一指数衰减，出现平台期
- 发光出现局域环带/旋转亮点
- 阻抗突变
- 上述信号在**无持续外部功率输入**时出现

## 5. 第四层：螺度自举（极低置信）

### 5.1 假设

如果 L3 成立（结构涌现），结构内部可能产生类似 alpha-dynamo 的效应：

- 核反应产物（如果后续引入）或磁重联产生的带电粒子
- 这些粒子在自磁场中运动，产生额外电流
- 额外电流补充螺度，补偿电阻耗散
- 实现"零持续外部输入"的真自持

### 5.2 类比来源

- Dynamo 理论（Parker 1955, Steenbeck-Krause-Rädler 1966）
- Alpha-dynamo 在天体物理中的观测（太阳发电机）
- 紧凑环实验中的自螺度再生（HIT-SI 团队）

### 5.3 诚实标注

这一层**纯属类比外推**，没有任何直接证据支持在低温等离子体+实体骨架系统中存在。Phase 0 不验证这一层。

## 6. 第五层：核反应耦合（远期假设）

### 6.1 假设

如果结构自持且内部粒子被强烈约束，轨道聚焦可能使局部碰撞能量远超热平衡分布，达到核反应截面。

### 6.2 为什么可能

- 聚变截面是速度的指数函数，非麦克斯韦尾部的少量高能粒子可能贡献不成比例的增益
- 拓扑约束可能把碰撞参数从各向同性变成定向聚焦

### 6.3 为什么极不可能

- 低温等离子体（~3eV）到聚变阈值（~10keV）差 3000 倍
- 没有任何机制能在厘米尺度聚焦到 keV 级
- 这一层目前纯属思想实验

### 6.4 定位

L5 是**远期愿景**，不是实验计划。如果 Phase 0 成功，再考虑要不要引入。

## 7. 判据的数学定义（v0.2 修订）

### 7.1 电阻扩散时间 τ_R —— 先用它校准"什么叫快/慢"

柱坐标下磁扩散方程给出粗略量级：

$$\tau_R \sim \frac{\mu_0 L^2}{\eta}$$

其中 $L$ 是场变化的特征尺度（腔体半径量级 ~15 cm），$\eta$ 是电阻率（Spitzer 形式 $\eta \propto T_e^{-3/2}$）。

**先用它校准"什么叫快/慢"** —— 这是 v0.2 相对第一版最大的改动。

- 如果 τ_R 只有微秒级（冷等离子体电阻率很高），那"维持时间 > τ_R"是必然满足的，不构成任何证据。
- 如果 τ_R 算出来是 ~10 ms 量级（高温、大尺度），那么"比它慢 3 倍"才有意义。
- **因此 v0.2 把"关断后维持 > 3×τ_R"作为核心判据之一，而不是用 1 ms 这种任意阈值。**
- 同时保留一条**绝对时间**兜底：包络衰减时间常数 τ_e > 25 ms。25 ms 的选取来自"普通 spheromak 关断后磁能 ~10 ms 量级衰减"这一经验量级——比它再慢一个台阶，才进入"值得复核"区间。它不来自任何理论推导。

### 7.2 三条必须同时满足的磁场判据

对关断后的 Bdot 信号（以某通道为例）：

1. **包络慢衰**：对 $|Bdot|$ 做 Hilbert 包络、并 <100 Hz 低通，拟合 $\tau_e$（指数衰减时间常数），要求 $\tau_e > 25\ \text{ms}$。
2. **快于扩散**：$\tau_e > 3\,\tau_R$（τ_R 按上面公式用实际腔体尺寸与 $T_e$ 估算，写入 `_meta.json` 的 `tau_r_ms`，供 analyzer 读取）。
3. **非指数**：bootstrap 检验 $H_0$："关断后包络是指数衰减"；要求 $p < 0.05$（单尾，拒绝 $H_0$ 才支持非指数）。

三条同时满足 => `field_candidate`。任何一条不满足，只算"长衰减"，不算候选。

### 7.3 独立加分项（不单独判候选，避免误报）

- **发光持续**：关断后 >2 ms 且 > 2× 关断前基线（基线取关断前 20 ms 窗口，**不取整段放电均值**——放电期间发光比关断后高得多，取整段会把阈值顶上去，导致"发光持续"永远判不出，这是第一版的实际 bug）。
- **阻抗跳变**：关断前后 $|V/I|$ 比值 > 2 或 < 0.5。

综合候选 = 磁场候选 **且**（发光持续 **或** 阻抗跳变）。

### 7.4 适应度函数

$$F = \frac{\tau_e \times V_{\text{pp}}}{E_{\text{inj}}}$$

- $\tau_e$：包络衰减时间常数（ms）
- $V_{\text{pp}}$：Bdot 关断后峰峰值（反映结构强度）
- $E_{\text{inj}}$：本次放电注入能量（J）

**F 只用于进化引擎的搜索排序，不是效率，不是 Q 值，不能和外推功率。**
Phase 0 的判定只用第 7.2 / 7.3 节的布尔判据。

### 7.5 为什么这样改能降低误报（第一版的教训）

第一版用"维持时间 > 1 ms + 非指数(R²<0.95) + 发光持续"判候选，有两个实际漏洞：

- 测试数据里一条"缓慢平台"被算成维持 24.33 ms，但非指数检验不显著 → 第一版把它当候选，而真实 spheromak 的磁能在同样条件下也能维持几十 ms。也就是说第一版**既可能漏掉真信号，又可能把普通余辉当候选**。
- 发光判据因基线取自整段放电，永远不触发。

v0.2 改为"τ_e + τ_R 比值 + bootstrap p 值"三层约束，并把发光、阻抗降为加分项。代价是判据变严、更难出候选——这是故意的：**宁可漏报，不可把普通余辉当自持**。

## 9. 待推导/待验证的问题

以下问题 Phase 0 开始前需要有人算清楚（贡献者欢迎 PR）：

1. **τ_R 的实际量级**（第一优先级）
   - 用腔体半径 L ~ 15 cm、预计 $T_e$ 代入 Spitzer 公式，给出 τ_R 范围。
   - 如果 τ_R < 1 ms，则"3×τ_R"判据基本失效，需改用纯绝对时间 + 非指数判据。
   - 这决定整套判据能否成立。

2. **种子尺寸的最优尺度**
   - 德拜长度：0.1~1 mm（太小）
   - 拉莫尔半径：电子 ~ mm 级，离子 ~ cm 级
   - 湍流相关长度：未知，需估算
   - **本轮先用 1~5 cm 试，不预设公式**（第一版"德拜×10~100"没有依据，已撤回）。

3. **鞘层电势是否足够驱动集体运动**
   - 需要估算：鞘层电势 → 离子加速 → 撞击能量 → 溅射产额 → 二次电子流 → 等效电流密度
   - 如果等效电流密度 < 所需阈值，L2 可能不成立

4. **bootstrap 判据的假阳性率实测**
   - 用空腔（无种子）重复放电 30 次，统计非指数检验 $p<0.05$ 的出现频率。
   - 若显著高于 5%，说明需要收紧判据或改用其他检验。

5. **扭结几何的拓扑不变量是否影响终态**
   - 三叶结（绕数 3）vs 八字结（绕数 4）vs 五角结（绕数 5）
   - 是否需要计算各自的环绕数/扭数/螺旋度

6. **模拟预筛**
   - 用 PIC 或 MHD 模拟预筛种子骨架几何，减少实验次数
   - 可选工具：OSIRIS (PIC), BOUT++ (fluid), Gkeyll (kinetic)

7. **knot_type / windings 是否进入搜索空间**
   - 当前进化引擎只学"可从实验参数重建"的 8 个参数，不学 knot_type / windings：因为 DAQ 元数据没写这两列，读了会得到 NaN，被当 0 处理，产生幻觉特征。
   - 后续若 DAQ 补写这两列，可把它们编码后加入进化空间。

## 10. 一句话总结

> L1（鞘层）是已知的，L2（几何引导）是理论支持的，L3（拓扑涌现）是本项目要验证的核心赌注。L4/L5 是远期愿景。Phase 0 只验证 L1→L3，用最少的钱、最简单的设备。
